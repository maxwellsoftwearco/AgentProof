Verifiable receipts for AI agents

Proof of what your AI agents actually did.

AgentProof creates tamper-evident receipts for AI-agent actions so developers can record, verify, and prove what happened.

Get Started View API Docs

How it works

Give your AI agent an AgentProof API key and record important actions through the API or SDK.

1. Record

Your application sends AgentProof information about an AI agent action.

2. Hash

AgentProof creates a cryptographic hash from the recorded information.

3. Verify

Anyone with the receipt can verify whether the recorded information still matches its original hash.

Example receipt

Every receipt identifies the agent and the action that was recorded.
