VERIFIABLE AI AGENT ACTIONS

Proof of what your AI agents actually did.

AgentProof creates tamper-evident receipts for actions performed by AI agents. Record what happened, verify the integrity of the record, and share proof with anyone.

Get Started API Documentation

Why AgentProof?

As AI agents begin taking real actions, organizations need a reliable way to record what those agents did and verify that the records have not been modified.

Record

Create a receipt containing the agent, action, timestamp, authorization status, result, and additional metadata.

Verify

AgentProof calculates a SHA-256 hash so the receipt data can be checked for unexpected modification.

Share

Every receipt has a verification URL that can be shared with another person or system.

Simple API

Your application sends an agent action to AgentProof. 

POST /receipts

{
  "agent_id": "customer-support-agent",
  "action": "send_email",
  "authorization_status": "authorized",
  "result_status": "success"
}
