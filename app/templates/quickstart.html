Getting Started

Start recording AI actions in minutes.

AgentProof creates verifiable receipts for actions performed by AI agents. Each receipt records what happened, who did it, whether it was authorized, and whether the record still matches its original integrity hash.

Step 1

Create your API key

Your application uses an API key to securely send actions to AgentProof. You only need to create one key for your application.

Create API Key
Step 2

Record an AI action

When your AI agent performs an important action, send AgentProof the basic information about what happened.

You do not need to understand cryptography or hashing. AgentProof handles that part automatically.

Step 3

AgentProof creates the receipt

AgentProof generates a unique receipt ID and a SHA-256 integrity hash. The receipt also gets its own verification URL.

Receipt created successfully
Your application receives the receipt ID and verification URL.
Step 4

Share the verification URL

Anyone who has the verification URL can view the receipt and check whether the stored data still matches the original hash.

VERIFIED

The stored receipt data matches the calculated hash. The receipt has not been detected as modified.

What is included in a receipt?

  • Unique receipt ID
  • AI agent name
  • Recorded action
  • Authorization status
  • Result status
  • Timestamp
  • SHA-256 integrity hash
  • Public verification URL
