Quick Start

AgentProof creates verifiable receipts for actions performed by AI agents.

When an agent performs an important action, AgentProof records what happened and creates a receipt that can later be independently verified.

How it works

Step 1

Create an API key

Your application uses an API key to authenticate with AgentProof.

Create API Key
Step 2

Record an agent action

Send AgentProof information about what the agent did. 

POST /receipts

{
  "agent_id": "customer-support-agent",
  "action": "send_email",
  "timestamp": "2026-08-21T00:00:00Z",
  "authorization_status": "authorized",
  "result_status": "success",
  "metadata": {
    "email": "customer@example.com"
  }
}
Step 3

Receive a receipt

AgentProof returns a unique receipt ID, an integrity hash, and a verification URL. 

{
  "receipt_id": "AP-EXAMPLE123",
  "record_hash": "sha256...",
  "verification_url": "https://agentproof-dydt.onrender.com/verify/AP-EXAMPLE123"
}
Step 4

Share the verification URL

Anyone with the verification URL can open the receipt and independently check whether the stored data still matches its original SHA-256 hash.

VERIFIED

The stored receipt data matches the calculated hash. The receipt has not been detected as modified.

What AgentProof gives you

Every receipt provides:

  • A unique receipt ID
  • The AI agent that performed the action
  • The action that was recorded
  • Authorization status
  • Result status
  • A timestamp
  • A SHA-256 integrity hash
  • A public verification URL
