Build trust into your AI agents.

AgentProof records important actions performed by AI agents and creates verifiable receipts. Each receipt includes the agent, action, result, timestamp, and an integrity hash.

How AgentProof works

1

Create an API key

Your application uses an AgentProof API key when sending information to the service.

You can create your API key through the API Reference.

2

Record an AI-agent action

When your agent performs an important action, send the action to AgentProof.

Request
POST /receipts

{
  "agent_id": "customer-support-agent",
  "action": "send_email",
  "timestamp": "2026-08-21T00:00:00Z",
  "authorization_status": "authorized",
  "result_status": "success",
  "metadata": {
    "email": "customer@example.com"
  }
}
3

AgentProof creates a receipt

AgentProof generates a unique receipt ID and calculates a SHA-256 integrity hash for the recorded information.

Example response
{
  "receipt_id": "AP-EXAMPLE123",
  "agent_id": "customer-support-agent",
  "action": "send_email",
  "result_status": "success",
  "record_hash": "sha256...",
  "verification_url": "https://agentproof-dydt.onrender.com/verify/AP-EXAMPLE123"
}
4

Verify the receipt

The receipt has a verification URL that can be shared with anyone who needs to check the record.

VERIFIED

AgentProof recalculates the receipt's hash and compares it with the original stored hash. If they match, the receipt data has not been detected as modified.

What is in a receipt?

Every receipt records the information needed to understand what an AI agent did.

  • Receipt ID — unique identifier for the record
  • Agent ID — identifies the AI agent
  • Action — describes what the agent did
  • Authorization — records whether the action was authorized
  • Result — records whether the action succeeded or failed
  • Timestamp — records when the action occurred
  • Metadata — additional information about the action
  • SHA-256 hash — protects the integrity of the receipt
  • Verification URL — lets others check the receipt

API endpoints

These are the main endpoints currently available in AgentProof.

Create an API key

POST /api-keys

Creates a new API key for your application.

Create a receipt

POST /receipts

Records an AI-agent action and returns the new receipt.

Get a receipt

GET /receipts/{receipt_id}

Retrieves a receipt and checks its integrity.

Verify a receipt

GET /verify/{receipt_id}

Opens the human-friendly verification page for a receipt.

Using the API

You do not need to memorize the API format. AgentProof provides an interactive API reference where you can see each endpoint, enter your information, and test requests.

Keep your API key private.

Your API key should be stored securely in your application. Do not publish it in public source code or send it to other people.
